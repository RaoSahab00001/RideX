RideX Complete Client App Prototype

Open RideX_Complete_Client_App_Prototype.html in Chrome/Edge.

This version is designed as an interactive product demo rather than a static dashboard.

Demonstrable journeys:
1. Passenger: booking -> AI driver matching -> ride confirmation -> live tracking -> payment -> rating.
2. Passenger: immediate/scheduled ride -> saved places -> payment -> SOS.
3. Driver: online status -> incoming request -> accept -> navigation -> earnings -> SOS.
4. City Support: ticket queue -> live ride assistance -> SOS monitoring -> escalation.
5. Central Admin: live fleet -> revenue -> payouts -> ratings -> AI dispatch -> demand/surge -> safety.
6. KYC/Aadhaar concept: OTP/KYC verified status without displaying or storing sensitive identity data.
7. Future concepts represented: dual mapping, AI dispatch, predictive demand, payment gateway, emergency escalation.

This is a front-end prototype. Real OTP, KYC/Aadhaar, GPS, Maps/Mappls, payment gateways, backend APIs, databases, notifications and emergency-authority integrations are not connected.
